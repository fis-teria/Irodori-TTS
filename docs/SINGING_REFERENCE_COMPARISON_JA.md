# 歌唱変換の参照音声比較（Irodori 生成参照 vs 実録音参照）評価レポート

対象: Irodori-TTS v4.1-Small + Seed-VC v1 歌唱モデルによる歌声変換。実施日 2026-11-01、RTX 4080 1 台。
結果の数値・ハッシュ・コマンドは実験フォルダ `outputs/singing/reference_comparison_<timestamp>/`
（git 管理外）の `summary.json` / `eval.json` / `vc.json` / `refs.json` / `setup.json` / `provenance.json` にあります。
音声・書き起こし・個人データのパスはこのレポートに含めていません。

## 結論（先に要点）

- **Irodori 本体で歌唱を作る開発（ネイティブ歌唱化）は現時点では保留を推奨**します。
  今回は、Irodori を参照生成に挟むことによる一貫した優位性を確認できませんでした。
  話者類似度の指標は目標の参照録音と元歌唱のスコアが重なり、人が聴いた再現度や品質の優劣は未判定です。
  ネイティブ化で改善すべき点を確定するには、試聴と追加の切り分けが必要です。
- 旧比較（A: 汎用女性声の Irodori 参照 vs B: 実録音 25 秒）は、**目標話者の指定が異なる・長さ 8.12 秒 vs 25 秒・
  音量差・VC 乱数シード未記録**のため観察結果にすぎず、「合成参照だから劣る」とは言えませんでした。
  今回、同じ目標話者を Irodori で複製した参照（C）を加え、長さと音量を揃え、VC シードを固定して比較しました。
- 同じ声を目標にした比較（C vs B）では、変換前の複製音声の話者特徴スコアが Irodori の乱数シードで変わりました
  （3 シードで 0.868〜0.939）。SVC 用のシード 0 はこの指標では最も低い値でした。
  ただし評価できた窓が少なく、指標の識別力にも限界があるため、聴感上の損失がどの段階で生じたかまでは特定できません。
- Irodori の音声コーデック（DACVAE）往復では、今回の区間の音程・話者特徴・音量包絡の保持を確認しました（後述）。
  一方、利用者の比較試聴では「微妙に変化」「ノイズが多くなった感じ」と指摘されました。
  コーデックの聴感品質は合格扱いにせず、ネイティブ化より先に前処理と往復劣化を切り分ける必要があります。
- 利用者から試聴セット全体について **似方 3/5・自然さ 2/5** の評価を取得しました。
  特に自然さに改善課題が残るという評価です。ただし条件別の採点ではなく、A/B/C の聴感上の順位や原因までは特定できません。

## 1. 旧 A/B 比較の監査（観察のみ）

| 項目 | 旧 A（汎用 Irodori 参照） | 旧 B（実録音参照） |
| --- | --- | --- |
| 参照の話者 | キャプション指定の汎用女性声（目標話者ではない） | 目標話者の実録音 |
| 参照の長さ / 音量 | 8.12 秒 / RMS -17.0 dBFS（48 kHz） | 25.0 秒 / RMS -25.0 dBFS |
| 元歌唱区間・VC 設定 | 15〜35 秒、30 steps、cfg 0.7、fp16、移調なし（両者同一、元音声ハッシュ一致） | 同左 |
| VC 乱数シード | 記録なし | 記録なし |
| 出力 RMS | -13.98 dBFS（ピーク 0.992） | -19.24 dBFS |
| 元歌唱の有声フレームのうち出力も有声 | 91.1 % | 86.3 % |
| 元歌唱の有声フレーム全体に対する ±50 cent 以内 | 84.1 % | 81.1 % |
| 両方有声のフレームだけでの ±50 cent 以内 | 92.3 % | 93.9 % |

旧レポートの「±50 cent 以内 92.1 % vs 93.9 %」は分母（両方有声のフレーム）が条件ごとに違うため、
B が良いとは言えません。分母を元歌唱の有声フレームに揃えると順序は逆になります。
参照音量を揃えた今回の A は -20.1 dBFS となり、旧 A の音量の優位は再現しませんでした。
乱数なども旧実行と異なるため、参照音量だけが原因だったとは断定できません。

## 2. 実験条件

- 目標の参照録音（約 50 秒）を **前半 25 秒（条件付け用）** と **後半約 25 秒（Irodori 参照生成・Seed-VC 変換の条件付けには未使用）** に分割。
  後半は評価用 WavLM とコーデック往復試験には入力しています。
- 元歌唱: 分離済みボーカル曲の 15〜35 秒（旧比較と同一、SHA-256 一致を確認）。
  利用者から、既に声変換された音声ではなく元の歌手のボーカルであると確認済みです。歌手名・声優の同一性は別途照合していません。
- 参照 3 条件（いずれも 44.1 kHz モノラル、**長さ 8.12 秒**、話している区間の RMS を **-24 dBFS** に揃え、ピーク上限 -1 dBFS、制限発動なし）。
  8.12 秒窓は各音声の中で発話区間が最も長くなる位置を選択。

| 条件 | 内容 | 発話区間の長さ | ゲイン |
| --- | --- | --- | --- |
| A 汎用 | 旧 A と同じ Irodori 汎用女性声（キャプション指定、話者参照なし） | 5.16 秒 | -8.86 dB |
| B 実録音 | 目標話者の前半 25 秒から切り出し | 5.97 秒 | -2.20 dB |
| C 複製 | Irodori v4.1-Small が前半 25 秒を話者参照にして旧 A と同じ文を読み上げ（キャプションなし、TTS シード 0） | 5.60 秒 | -8.39 dB |
| 補足 B 25 秒 | 前半 25 秒全体（長さを揃えない場合の参考） | 14.58 秒 | -1.31 dB |
| 探索 C' | C と同条件で TTS シード 2 の複製（**事前指標を見て選んだ後付け条件**、計画外） | 5.22 秒 | -8.70 dB |

- Seed-VC: v1 歌唱モデル（f0 条件付き 44.1 kHz）、30 steps、cfg 0.7、fp16、移調なし、長さ調整なし。
- VC 乱数シード 0 と 1 を全条件で共有。上流の推論コードにシード指定がないため、実験専用ラッパー
  `singing_vc/seeded_seedvc.py` で random / numpy / torch / CUDA を設定してから既存ランナーを呼び出しました（本番 API は無変更）。
- 再現性: B・シード 0 を 2 回実行し、**波形サンプルは完全一致**（WAV ヘッダの 3 バイトのみ差）。一方シード 0 と 1 では波形が大きく異なります（差分 SNR 約 -1.9 dB）。
- 各モデルは別プロセスで順番に実行し、GPU 上に同時に載せていません。

## 3. 話者類似度の代理指標（WavLM-SV）

`microsoft/wavlm-base-plus-sv`（ローカル既存スナップショットを読み取りのみで使用）で、発話・歌唱が 60 % 以上を占める
重なりなしの 4 秒窓ごとに x-vector を計算し、各窓を正規化→平均→再正規化した重心どうしのコサイン類似度を使いました。
このモデルは話し声で学習され、VoxCeleb1 で話者照合向けに調整されています。閾値はデータ依存です
（[モデルカード](https://huggingface.co/microsoft/wavlm-base-plus-sv)）。**値は似ている度合いの百分率ではなく、話し声→歌声の領域差にも影響されます。**
SVCC 2023 でも客観指標の多くは主観評価と有意に相関しませんでした（[arXiv:2306.14422](https://arxiv.org/abs/2306.14422)）。

### 指標自体の較正

評価専用区間（後半）の重心との類似度:

| 比較対象 | 類似度 |
| --- | --- |
| 同じキャラクター名のフォルダーにある別録音 2 本 | 0.961 / 0.963 |
| 同じ話者の前半 25 秒（条件付け区間） | 0.950 |
| 評価区間内の前半半分 vs 後半半分 | 0.873 |
| 別キャラクター名のフォルダーにある録音 12 本（匿名） | 0.775〜0.944（平均 0.883） |
| **元歌唱者（曲の変換区間以外）** | **0.938** |
| 元歌唱区間そのもの | 0.953 |

フォルダー名は人間の話者識別ラベルとして検証されておらず、別キャラクターでも同じ声優の場合があります。
同じフォルダーの別録音は全候補中で 1 位になりました。しかし**元歌唱者は別フォルダー録音の上位と同程度に
目標話者へ近く、変換前の元歌唱区間でさえ目標話者が最上位に来ます**。したがって、この指標で
「元歌唱者の声が残っているか」や「目標話者にどれだけ近づいたか」を判定することはできません。以下の値は参考程度です。

### 結果（VC シード 0/1 の平均 [最小〜最大]）

| 条件 | 評価区間の目標話者との類似度 | 元歌唱者との類似度 | 別フォルダー録音 12 本に対する z 値 | 14 候補中の目標の順位（シード 0 / 1） | 自分の参照との類似度 |
| --- | --- | --- | --- | --- | --- |
| A 汎用 | 0.925 [0.923〜0.927] | 0.916 | 0.63 | 4 / 4 | 0.949 |
| B 実録音 | 0.940 [0.928〜0.952] | 0.905 | 0.92 | 3 / 3 | 0.925 |
| C 複製 | 0.932 [0.930〜0.934] | 0.910 | 0.61 | 3 / 6 | 0.921 |
| 補足 B 25 秒 | 0.955 [0.947〜0.963] | 0.910 | 1.18 | 3 / 1 | 0.951 |
| 探索 C'（TTS シード 2） | 0.945 [0.941〜0.948] | 0.914 | 0.87 | 3 / 3 | 0.945 |

並びは B 25 秒 ≥ C' ≈ B ≥ C ≥ A ですが、B のシード間の幅（0.024）が条件間の差と同程度で、
元歌唱者・他話者の上位（0.938〜0.944）とも重なります。1 話者・1 曲・シード 2 個であり、差があるとは言えません。

| B 実録音 8.12 秒 | 0.937 | 1 |

ただし、この指標は声の再現度を十分に識別できておらず、元歌唱の影響の強さや聴感上の損失の原因を特定する根拠にはできません。

## 4. 音高・音量・タイミング

pYIN（16 kHz、10 ms、65〜1100 Hz）で元歌唱と同じフレーム位置を比較しました。分母は**元歌唱で有声のフレーム全体**（1659 フレーム）で、
出力が無声・無効値になったフレームや、出力が短く欠けた末尾も失敗として数えます。両方有声のフレームだけの値は別に示します。

| 条件 | 出力も有声 | ±50 cent 以内（全体） | ±50 cent 以内（両方有声のみ） | 誤差中央値 | log-F0 相関（両方有声） | 出力 RMS |
| --- | --- | --- | --- | --- | --- | --- |
| A 汎用 | 91.2 % | 84.5 % | 92.7 % | 10 cent | 0.994 | -20.1 dBFS |
| B 実録音 | 87.8 % | 82.8 % | 94.3 % | 10 cent | 0.996 | -18.3 dBFS |
| C 複製 | 87.5 % | 82.5 % | 94.2 % | 10 cent | 0.961 | -19.7 dBFS |
| 補足 B 25 秒 | 84.7 % | 80.1 % | 94.5 % | 10 cent | 0.997 | -20.6 dBFS |
| 探索 C' | 88.4 % | 82.5 % | 93.3 % | 10 cent | 0.927 | -19.4 dBFS |
| 参考: DACVAE 往復 | 98.9 % | 92.7 % | 93.7 % | 0 cent | 0.996 | — |

- オクターブ誤りは全条件で 0〜0.2 %。クリップしたサンプルはなし。長さは全条件で 19.99 秒（入力 20 秒）。
- A は有声として残るフレームが多く、B/C は両方有声のフレームでの一致が高い、という交差した傾向です。どちらが良いとは決められません。
- C 系だけ log-F0 相関が低めで、少数の大きく外れたフレームがあると考えられます（試聴で確認が必要）。
- 音量の包絡（10 ms フレームの dB 値）の相関は全条件 0.89〜0.92、最適なずれは 0〜10 ms。
  これは大まかな時間的一致の目安で、音素や音符の頭の位置合わせではありません。
- Whisper-small による書き起こしを元歌唱の書き起こし（正解歌詞ではない擬似参照、約 35 文字）と比べた文字誤り率は、
  A 0.26、B 0.26、C 0.33、B 25 秒 0.21、DACVAE 往復 0.20 でした。1 文字で約 0.03 動く程度の小さな標本で、
  Seed-VC の内容エンコーダも Whisper 系なので独立した測定でもありません。歌詞の聞き取りやすさの評価としては扱いません。

## 5. ネイティブ化の最初の関門: DACVAE コーデック往復

Irodori の DACVAE コーデックで元歌唱 20 秒をエンコード→デコードしました（TTS モデルは不使用、音量正規化なし、25 latent フレーム/秒 × 32 次元）。
元歌唱の有声フレームの 98.9 % が有声のまま残り、±50 cent 以内 92.7 %（pYIN による推定値で、評価法やコーデックの上限ではありません）、
WavLM の類似度は元歌唱区間に対して 0.996、音量包絡の相関 0.998 でした。
この区間の歌声を潜在表現から再構成し、上記の特徴を保持できたことは確認しました。
利用者は元歌唱と往復音を比較して「微妙に変化を感じるね、ノイズが多くなった感じがする」と回答しました。
自然さの数値採点はありませんが、聴感上のノイズ増加を感じたという所見があるため、品質の関門は通過扱いにしません。
音量を揃えた元音との比較、前処理設定・符号化/復号条件・別コーデックなどでの切り分けが先です。
広い音域の保持と、TTS が歌声を生成できるかも別途確認が必要です。
なお、実録音を直接参照する B の Seed-VC 経路には Irodori の DACVAE は含まれません。
試聴セット全体の自然さ 2/5 を DACVAE 一つの原因で説明することはできません。

## 6. 交絡と限界

- 1 話者・1 曲・20 秒区間・VC シード 2 個のみ。統計的有意性や一般化は主張しません。
- 参照録音と歌声では発声・音域・録音条件が異なります。話し声で学習した話者照合モデルは、この領域差でも値が変わります。
- 話者類似度の指標は目標話者と元歌唱者をほとんど区別できませんでした（§3）。
- 8.12 秒の参照では 4 秒窓が 1〜2 個しか取れず、参照音声側の類似度は窓数が少ない分だけ不安定です。
- 参照の発話区間の長さは 5.2〜6.0 秒で、完全には揃っていません（値は記録済み）。
- C' は事前の類似度を見てから選んだ条件で、選択バイアスがあります。計画した比較は A/B/C のみです。
- Irodori の生成音声には透かし（silentcipher）が入ります（A・C 共通）。影響は評価していません。
- 補助話者埋め込み CAMPPlus は Seed-VC 自身が使うため独立性がなく、使っていません。音声 MOS 予測器も歌声には使っていません。

## 7. 推奨と判断条件

**判断: ネイティブ Irodori 歌唱開発は保留。** 次の順に進めることを推奨します。

1. **取得した試聴評価を起点に切り分ける**。利用者の全体評価は似方 3/5・自然さ 2/5 でした。
   コーデック往復にも「ノイズが多くなった感じ」と回答があり、まず往復劣化と前処理を確認します。
   条件別の点数や元歌唱との比較で、元音源・コーデック・参照音声・SVC の問題を区別します。
   集合的な低評価だけで原因を一つのモデルに確定しません。元歌唱とコーデック往復が自然で、変換後だけ不自然なら、SVC 側の改善を先に検討します。
2. 試聴で **B が目標話者らしく、C が B に近い** 場合: 現行の Irodori + Seed-VC 構成を維持し、
   複製参照は TTS シードを複数生成して、実録音（条件付け区間）に最も近いものを選ぶ運用にする（今回のシード差が示す改善余地）。
   実録音があるなら実録音参照を優先する。
3. 試聴で **B でも目標話者らしくない（元歌唱者の声が残る）** 場合: 参照区間・前処理・発声領域の差と、
   Seed-VC の変換能力を先に切り分けます。目標話者データでの Seed-VC 微調整や既存の話者別 VC モデルとの比較も候補です。
   この結果だけで原因を参照またはモデルの一方に確定することはできません。
4. **元の歌声を入力する目的のままでも、Irodori 本体に内容・F0 条件を加えて歌声を再生成する研究は選択肢です。**
   ただし、現行方式に残る問題を複数話者・複数曲の試聴で確認し、対応する歌唱データと評価方法を用意してから、
   独立した小規模実験として判断します。今回の結果だけで本体の改修・大規模再学習へ進む根拠は不足しています。
   元歌唱を使わない歌詞・楽譜からの生成は、さらに別の要件として扱います。

## 8. 試聴セット

`listening_pack/` に、シードと条件を伏せた X01〜X06（A/B/C × VC シード 0/1）、
目標話者の評価区間 20 秒、元歌唱区間、DACVAE 往復音を収めています。全ファイルは減衰だけで話している区間の RMS を
-28.7 dB に揃え、ピークは -1 dBFS 以下です。対応表は別フォルダ `listening_key/key.json`、採点方法は `RUBRIC_JA.md`
（`docs/SINGING_LISTENING_RUBRIC_JA.md` と同一）にあります。

利用者 1 名から「全体として程度はあれど、似方３、自然さ２な感じはする」と回答を取得しました。
これは全セットへの概括的な評価で、各ファイル・条件の個別点数や統計的な MOS ではありません。
さらに元歌唱とコーデック往復の比較に対し、「微妙に変化を感じるね、ノイズが多くなった感じがする」と回答を取得しました。
原音と往復音の個別点数は未取得です。条件別順位、複数評価者での再現性、ノイズの定量評価も未確認です。
音声自体は自動指標を計測したもので、エージェントが聴取したと称する評価は含めていません。
