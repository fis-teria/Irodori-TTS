# 歌唱変換 ブラインド試聴ルーブリック

`X01.wav` 〜 `X06.wav` は条件と乱数シードを伏せて並べ替えた変換結果です。全ファイルは減衰のみで
アクティブ区間 RMS を揃えてあります（音量差で判断が偏らないため）。対応表は別フォルダ
`listening_key/key.json` にあり、採点が終わるまで開かないでください。

## 手順

1. `anchor_target_voice_heldout.wav`（目標話者の実音声、条件生成に未使用の区間）を聴き、声の特徴を覚える。
2. `anchor_source_song_excerpt.wav`（元歌唱）を聴き、旋律と歌い回しを確認する。
3. X01〜X06 を任意の順で聴き、下表を 1〜5 で採点する（同点可）。各ファイル 2 回以上聴く。
4. 可能なら日を変えて、または別の人にも同じ採点をしてもらう。
5. 採点後に key を開き、条件ごと（A/B/C）にシード 0/1 の平均とばらつきを見る。

## 採点項目（1 = 悪い / 5 = 良い）

| 項目 | 観点 |
| --- | --- |
| 話者らしさ | 目標話者の声に聞こえるか（声質・年齢感・癖）。元歌唱者の声が残っていないか |
| 発音・明瞭さ | 歌詞の母音・子音がつぶれていないか、元歌唱と同じ言葉に聞こえるか |
| 自然さ | 人が歌っているように聞こえるか、機械的・ざらつき・こもりがないか |
| 高音・ロングトーン | 高音で声が裏返る・割れる・細くなる、伸ばしで揺れや途切れがないか |
| 破綻・ノイズ | クリック、金属音、息のノイズ、無音化、音程外れなどの目立つ不具合 |

各ファイルに自由記述欄（気になった秒数と内容）を設けてください。
